定点色写入工具 · VertexColorWriter
=================================

# 项目概览

在线美术使用指南（飞书）：
https://t6bdpf8yjg.feishu.cn/docx/NTends7mso2kijx79Q5cWL3mnOf
包含常用操作步骤、1 米高度对齐示例、流程图、参数表与常见问题。

MaxZJTools v1.7.0 / VertexColorWriter v1.4.0。
支持高度双色渐变、固定颜色填充，以及按 UV 将图片颜色写入选中模型。R、G、B、A 可分别勾选，
未勾选的分量保留原值。中文名称按用户要求使用“定点色写入工具”。
写入范围可选“整个模型”或“选中顶点”；三种模式都支持局部写入，其他顶点保留原值。
作用于当前帧、点击写入时的场景选择；修改修改器栈，不自动保存 .max、不保存副本、不导出文件。
另提供当前模型高度读数与视口标尺；测量为只读，独立于颜色写入，不修改模型或映射高度。

# 功能说明与使用流程

## 定点色写入工具

### 菜单/入口

MaxZJTools > 定点色写入工具 > 对应动作；也可运行 tools/VertexColorWriter.ms。
宏类别 MaxZJTools，动作名 MaxZJTools_VertexColorWriter。
旧 ZHeightToVertexRed.ms 和 MaxZJTools_ZHeightToVertexRed 动作继续转到新工具。
界面正文 12 pt，标题区只保留窗口名称；左侧配置、右侧纵向/贴图预览、底部执行。
三个模式共用通道选择；切换到贴图模式后显示图片与 UV 参数，隐藏高度颜色配置。
模式下方增加“写入范围”与选点数量；选中顶点时只接受一个模型，未进入有效顶点模式或没有选点时禁用写入。
v1.6.0 起，模式、分区标题与主要按钮增加绿色扁平图标，原文字保留；主图标为彩色顶点网格与画笔。
新/旧宏动作绑定同一入口图标；自定义工具栏可使用 MaxZJTools_VertexColorWriter 动作。
配置区下方显示“当前模型高度 · 世界 Z（只读）”，右侧为“视口显示高度标尺”开关。

### 用途

高度渐变：先求统一高度权重 t，再对勾选的通道逐分量写入：
  t =（顶点世界 Z − 起点）/ 映射高度
  输出通道值 = 底部通道值 +（顶部通道值 − 底部通道值）× t

默认映射高度 1 米、起点世界 Z=0，R 通道勾选，底部黑色、顶部白色。
不同高度的模型共用同一个跨度，较矮模型的顶部不会自动达到顶部颜色。
可选“距各自底部高度”：每个对象从其当前网格最低顶点的世界 Z 开始，仍共用相同跨度。
所有高度测量沿世界 Z，并考虑对象/父级变换及缩放；不沿各自局部轴。

固定颜色：写入范围内的顶点使用“填充颜色”和其 Alpha；只覆盖勾选的通道，高度参数禁用且不参与计算。
例如范围选“选中顶点”、只勾选 G，将绿色分量设为 128，则选中顶点 G=128/255，其他顶点及 R/B/A 保持原值。

局部填充：单选模型，在 Editable Mesh / Editable Poly 或 Edit Mesh / Edit Poly 的顶点层级选点，
将写入范围切到“选中顶点”。数量显示为“已选 N / 总顶点数”，点击“写入 N 个选中顶点”。
只写连接网格面的硬选择点，软选择衰减不参与；孤立顶点不计入可写数量。面/边层级不自动转成顶点选择。
选点层上方仅允许本工具原有的颜色与转换修改器；其他修改器会阻止写入，并提示在栈顶增加 Edit Poly / Edit Mesh 后选点。
高度渐变仍使用原映射跨度及整模型最低点，不以所选顶点重新归一化。贴图仍逐面角采样，保留 UV 接缝。
每次点击重新捕获选择，空选择不会回退到整模型；完成后尝试恢复原修改器层级与顶点模式，便于换一批点继续填充。

贴图写入：读取一张图片，根据所选 UV 通道的每个面角坐标采样，写入对应的 R/G/B/A 分量。
同一个几何顶点在 UV 接缝两侧可以拥有不同的颜色；不合并接缝、不增加几何细分。
完整彩色通常勾选 RGB；读取透明度时再勾选 A。切换模式保留原有通道勾选，不自动改成全通道。
“颜色”将 sRGB 图片转换为线性 RGB 后采样；“遮罩”保持 0~1 原始通道数值，Alpha 始终不做伽马转换。
例如像素值 128：遮罩模式写入约 0.502，颜色模式写入约 0.216。图片没有 Alpha 时，勾选 A 写入 1。
该方式读取图片本身，不求值材质、灯光或贴图节点中的偏移、旋转、平铺和颜色校正。

高度测量：单选几何对象后，按当前帧的实际网格顶点测量世界 Z 的最高值减最低值，
显示模型高度及顶部/底部世界 Z，单位固定为米、保留三位小数。模型高度与映射高度分别显示。
考虑对象、父级、对象偏移、旋转和缩放；修改器塌陷后仍按当前选择更新读数。
标尺默认开启，在模型旁显示世界 Z 尺寸线和高度；视图投影太短时只显示高度，避免文字重叠。
取消选择、多选、删除对象或关闭工具时清除标尺。关闭开关只隐藏标尺，面板读数继续更新。

### 参数说明

| 参数 | 作用与输入范围/格式 | 默认行为 | 对输出的影响 | 约束与撤销 |
|---|---|---|---|---|
| 场景选择 | 一个或多个几何对象 | 通常每 0.5 秒更新，复杂测量时延长到最多 5 秒；点击写入时重新读取 | 逐个处理几何对象，其他对象跳过；测量仅限单选 | 无几何对象时禁用写入；成功批次可 Ctrl+Z |
| 写入范围 | 整个模型 / 选中顶点 | 整个模型，可多选批处理 | 前者覆盖整个几何对象，后者仅更新所选顶点关联面角的勾选通道 | 选中顶点要求单选模型与有效顶点模式；空选不写入；改范围不改场景，执行可 Ctrl+Z |
| 已选顶点数量 | 只读，N / 求值后网格总顶点数 | 随选择刷新，点击时重新捕获 | N 仅统计连接网格面的硬选择点；未选及孤立点不写入 | 不使用软选择权重；不支持边/面模式自动转换；读数无需撤销 |
| 当前模型高度 | 只读，无输入；显示米制高度与世界 Z 两端值 | 单选后自动更新，保留三位小数 | 不改变映射高度、网格、颜色或修改器 | 多选/空选择不合并计算；不写场景，无需撤销 |
| 视口显示高度标尺 | 布尔复选框 | 开启，仅单选几何对象时显示 | 临时绘制尺寸线、高度和顶部/底部文字 | 隐藏对象不画标尺；关闭或取消选择清除；不写场景，无需撤销 |
| 写入模式 | 高度渐变 / 固定颜色 / 贴图写入 | 高度渐变 | 在指定写入范围内，两端颜色插值 / 固定填色 / 按 UV 采样图片 | 切换保留写入范围与通道；贴图模式不使用高度参数；执行后可撤销 |
| R / G / B / A | 四个独立复选框，可任意组合 | 只勾选 R | 只覆盖勾选分量，未选分量保留 | 必须至少勾选一个；RGB 存于通道 0，A 存于 -2；可撤销 |
| 底部颜色 / 填充颜色 | 点击色块打开颜色对话框；RGB 各分量 0~255 | 黑色 #000000 | 转换为 0~1 浮点；用于高度起点或固定填充 | 只写勾选的 RGB；不勾选 RGB 时禁用色块；可撤销 |
| 顶部颜色 | 点击色块，RGB 各分量 0~255 | 白色 #FFFFFF | 高度终点颜色；中间按高度线性插值 | 固定模式禁用；只写勾选的 RGB；可撤销 |
| 底部/填充 Alpha | 0~1 小数，步长 0.01 | 0 | 高度起点或固定填充的 A；0 为透明值，1 为不透明值 | 只有勾选 A 时启用并写入；材质是否使用 Alpha 由下游决定；可撤销 |
| 顶部 Alpha | 0~1 小数，步长 0.01 | 1 | 高度终点 A，中间线性插值 | 仅高度模式且勾选 A 时启用；可撤销 |
| 对齐方式 | 同一世界高度 / 距各自底部高度 | 同一世界高度 | 前者共用起点，后者分别使用最低世界顶点 | 固定模式禁用；各自底部模式忽略起始高度；可撤销 |
| 起始高度（米） | -1000000~1000000 的小数，显示三位小数 | 0 | 共用的高度起点 | 仅世界高度渐变有效；可撤销 |
| 映射高度（米） | 0.001~1000000 的正小数，显示三位小数 | 1 | 从底部颜色到顶部颜色的跨度 | 不允许零或负数；不按模型自身高度归一化；可撤销 |
| 范围外使用两端颜色 | 布尔复选框 | 开启 | 将 t 限制为 0~1，范围外使用最近一端颜色 | 关闭会外推，可能产生负值或大于 1 的 RGBA；可撤销 |
| 完成后显示顶点色 RGB | 布尔复选框 | 关闭 | 尝试开启对象 RGB 顶点色显示 | 不直接显示 Alpha；可在对象显示设置关闭；显示状态撤销需宿主验证 |
| 选择贴图 | 单个 PNG/JPG/JPEG/BMP/TGA 文件路径 | 未选择；须成功读取才能写入贴图 | 批次所有模型共用加载时的图片内容 | 只读图片，不改文件；每通道 8 位，PNG 调色板/低位深会解码到 8 位；读图无需撤销 |
| 重新读取 | 按钮，无数值输入 | 不自动监视文件改动 | 重新读取当前路径，更新缓存和预览 | 文件修改后需点此按钮，再次写入才改变模型；失败清空旧缓存；读图无需撤销 |
| UV 通道 | 1~99 的整数 | 1 | 使用对应通道的 UV 面角采样，V=0 对应图片底部 | 对象缺少该通道或 UV 索引无效则该对象失败并回滚；不生成 UV；写入可撤销 |
| 贴图用途 | 颜色 · sRGB 转线性 / 遮罩 · 保持原始数值 | 颜色 | RGB 按 sRGB 曲线转线性，或保持字节值/255；Alpha 始终线性 | 不读取 ICC/OCIO 配置，不依据文件名猜测；选择与资产约定匹配的用途；写入可撤销 |
| 采样方式 | 双线性 / 最近点 | 双线性 | 双线性混合邻近四个像素；最近点直接取一个像素 | 颜色模式先转线性再插值；不自动增加模型顶点；写入可撤销 |
| UV 越界 | 截取 / 平铺 | 截取 | UV 超出 0~1 时使用边缘颜色或重复图像；平铺双线性在边界混合 | 两轴使用相同策略，无镜像/UDIM；越界面角计数在处理明细中；写入可撤销 |

> 纵向预览的上方是高处，下方是起点；中间标出半高。勾选 A 时用棋盘格展示设定的透明度。
> 预览表示配置的完整颜色，不是场景实时回读；未勾选通道保留各模型原值，因此实际合成色可能不同。
> 配置修改后需再次写入；处理明细保留上次执行参数与逐对象结果，不会自动改写旧结果。
> 图标为识别辅助，无额外参数，不改变写入值、模式或场景；缺少 PNG 时面板使用内置写入符号，无需撤销。
> 贴图原图预览只显示读入图片，不显示材质或实际顶点插值结果，也不随通道勾选改变原图。
> 批处理输入为点击写入时选中的几何对象，贴图为单一文件路径；不扫描目录、不做关键字匹配或自动命名。
> 无输出目录、不生成图片、不覆盖原图片或 .max；同名图片按完整路径区分，不自动匹配每个模型的贴图。
> 图片缺失/格式失败时禁用贴图写入；对象 UV 缺失只令该对象失败。重复写入只覆盖指定范围内的勾选通道。
> 局部写入不扫描目录，不创建按选点命名的副本；模型名不变，未选顶点和未勾选通道保留，结果可撤销。

### 输出结果

在工具转换修改器 VCW - Mesh Adapter 上方按需添加 VCW - RGB 和 VCW - Alpha。
RGB 单独写入时最多两个工具修改器，RGB 与 Alpha 都曾写入时最多三个，原模型不会被塌陷。
若已有本工具修改器仍连续位于栈顶，重复写入替换相关通道的旧结果；未勾选的另一通道修改器保留。
也识别原 ZHR 修改器对。中间插入其他修改器后，将新增一组，保留其下方原栈。
原本没有 RGB 时，首次写入 RGB 会创建颜色映射，未选 RGB 分量初始化为 0；原本没有 Alpha 时，
不勾选 A 就不创建 Alpha。只写 A 时不会刻意创建 RGB 通道。
局部写入首次创建 Alpha 时，未选顶点初始化为 1（不透明）；已有 Alpha 按面角保留原值。
首次创建 RGB 时，未选顶点与未勾选的 RGB 分量初始化为 0；原有 RGB 及颜色接缝按面角保留。
成功/失败数量显示在底部；“处理明细”和 F11 记录逐对象结果、执行参数及高度范围外顶点数/UV 越界面角数。
Ctrl+Z 撤销整个批次；关闭工具不撤销已有结果，不自动保存场景或导出。
贴图结果写入修改器数据，成功后显示/保存已有结果不再依赖源图片；修改 UV 或图片后必须重新写入。
关闭窗口释放图片缓存与缩略图。图片读取期间不创建材质、贴图节点或持久场景辅助对象。

高度测量的输出仅为面板读数与临时视口绘制；不会添加修改器、文字网格或辅助节点，
因此没有标尺对象参与 FBX/OBJ 导出，也不会被塌陷进模型。标尺本身不写入 .max。
关闭工具会注销本工具的绘制回调并释放缓存；重复打开/重载会先清理旧回调。
鼠标悬停在高度读数上可查看对象名；绘制异常时开关显示“标尺异常”，提示和 F11 可查看原因。

### 注意事项与已知限制

- 当前帧一次性写入，位置、形状、拓扑、缩放或动画姿态改变后需重新执行。
- 需要有面和顶点的几何对象；世界空间修改器不支持，蒙皮导出链路未验证。
- RGB 按面角保留颜色接缝，可能增加内存。大型网格处理期间界面可能暂时不响应。
- 选中顶点范围仅限单选模型；支持上述四种编辑层级，不支持软选择渐变、孤立顶点或其他类型的子对象选择。
- 局部写入读取求值网格上的选择标记，退出顶点模式前保存快照；转换后顶点位置/拓扑不匹配则取消并移除本次新增修改器。
- 选点层上方存在其他修改器时，请在最终要写入的层级添加 Edit Poly / Edit Mesh 后选点；不会自动塌陷模型。
- 使用 Max Channel Info 内部复制缓冲区，会覆盖其内容；不使用 Windows 文本剪贴板。
- 写后校验比较几何及 RGB/Alpha；贴图模式还比较使用的源 UV 面角值。失败对象移除本次新增修改器，其他成功对象保留结果。
- 纵向预览及 Alpha 棋盘格仅是 UI 示意；实际透明效果取决于材质、导出器与下游读取。
- 未提供独立 R/G/B/A 场景实时预览，不自动保存参数；关闭重开恢复默认值。
- 测量只支持单选几何模型；不合并多选对象，不以当前子对象选择作为测量范围。
- 世界空间修改器及无网格顶点对象无法测量，显示原因并清除旧标尺，不提供可能误导的高度值。
- 高度读数为定时采样；绘制回调只读缓存。复杂网格可能有延迟，不承诺逐帧动画测量。
- 顶视图或很小的模型只保留高度文字；透视视图中标尺跨越相机平面时暂不绘制。
- 视口标尺采用 Max 原生固定字体，不改变 Max 全局字体设置；实际 DPI/视口驱动显示尚待验证。
- 顶点色只能存储顶点/面角处的颜色，面内由下游插值；大面、少顶点无法保留图片中的小字或细纹。工具不自动细分。
- 只支持单张普通图片，不支持材质树烘焙、程序贴图、UDIM、HDR/EXR、TIFF、动画图片、投射或自动展开 UV。
- 图片每边最多 8192 像素，总像素不超过 16777216（如 4096×4096）；超限提示失败，不自动缩小。
- TGA 支持无调色板的 24/32 位真彩色、8 位灰度及 RLE；预乘 Alpha、交错扫描和 16 位真彩色不支持。
- PNG 每通道 16 位拒绝读取，需手工转为 8 位；颜色贴图按普通 sRGB 处理，其他色域需先转换。遮罩不要选颜色模式。
- 读取的是直通 RGB/Alpha；透明像素下的 RGB 也参与采样，双线性可能混入透明边缘的隐藏颜色，不自动做扩边。
- 重叠 UV 采样同一区域；跨平铺边界的大三角面仍受顶点插值限制。源文件改动不会自动更新缓存或场景结果。

# 安装与使用

保留 tools/VertexColorWriter.ms、tools/VertexColorWriterUI.cs、tools/VertexColorWriterTexture.cs 在同一目录。
整包保留 icons/。入口图标有 Dark/Light 两套，16/24/30/32/36/48/64 像素；面板主按钮使用 Dark 32 像素版。
首次安装在 Max 中运行 Install.ms；启动 Loader 仍指向完整工具包所在目录。
已有安装运行 startup/MaxZJTools_Init.ms，即可刷新新名称；旧快捷键和旧文件入口仍可用。
关闭旧窗口后从菜单重新打开读取新版，通常无需重启。源码缓存按实际界面文件内容更新。
Install.ms 只写入用户 startup 目录下的 MaxZJTools_Loader.ms；初始化脚本会复制本工具的 14 个 PNG 到
getDir #userIcons 对应目录下的 Dark/MaxZJTools 与 Light/MaxZJTools。只覆盖内容不同的同名本工具图标，不复制其他资源。
迁移目录后重跑安装器；不修改 Max 程序目录，也不修改 C:/LGPublic/Scriptlibrary/max/icons 参考库。
卸载：删除 Loader 并重启，不会删除场景里的修改器；可另行移除上述用户图标目录中的 VertexColorWriter PNG。
首次注册或更换图标会刷新图标缓存；若旧工具栏仍显示旧图标，重启 Max 后再查看。

使用：单选查看模型高度（可开关标尺）→ 选模式 → 勾通道 → 配颜色/Alpha → 设置映射范围 → 看预览 → 写入 → 保存。
贴图用法：准备有 UV 的模型 → 选“贴图写入” → 选择图片 → 确认 UV 通道 → 选择颜色/遮罩 → 勾 RGB 或所需 RGBA → 写入。
需要原值灰度时选“遮罩”；只勾 R 就写入图片红色分量，不自动把 RGB 转成亮度，也不提供分量间重映射。
批量写入仍可多选；多选时暂不显示单个模型的高度和标尺。
局部填充用法：单选模型 → 进入顶点模式选点 → 写入范围选“选中顶点” → 选“固定颜色” → 设颜色/Alpha 与通道 → 确认点数 → 写入。
需整模型批量处理时，将范围切回“整个模型”。高度和标尺始终测量整模型，不随选点范围改变。

# 技术与兼容性

目标宿主 3ds Max 2022。MAXScript 核心调用 mesh/meshop、ChannelInfo、Turn_to_Mesh 与 UVW_Mapping_Paste。
界面使用 Windows 内置 .NET WinForms，正文 Microsoft YaHei UI 12 pt，窗口内容基准 860×808。
不要求安装第三方库，也不分发二进制 DLL；首次打开从同目录 .cs 编译到内存，后续复用内容缓存。
Max 2022 使用 .NET Framework 编译器；提供 Max 2026+ 的 CSharpCompilationHelper 分支，尚未实测。
新菜单仍使用原 menuMan；其他宿主版本、实际 Max 内 DPI 缩放、Alpha 粘贴与导出均需目标环境验证。
外部资源：VertexColorWriterUI.cs 与 VertexColorWriterTexture.cs 必须随包保留；UI 主图标位于 icons/。
小型面板符号由 C# 绘制；主图标加载后不占用文件句柄，关窗释放位图。图标源文件和生成提示词见 icons/说明.txt。
图片由用户指定；需要在其他电脑重新烘焙时手工复制并重新选择图片，安装器/导出器不会由本工具自动打包它。
普通图片用 Windows System.Drawing 解码，TGA 由内置读取器处理；不求值 Max 的 BitmapTexture/渲染颜色管理。
测量只使用 snapshotAsMesh 内存网格与 objectTransform；临时网格在成功及失败路径均释放。
视口显示使用 registerRedrawViewsCallback 和 gw 绘制接口；取消/关闭时清理，不创建可导出的场景实体。
本工具不执行导出或资源打包；FBX/Unity 的颜色精度、范围与 Alpha 支持需回读验证。
旧 ZHR_* 函数保留原默认局部坐标/米/R-only 调用行为；新 VCW_BakeNode 默认世界坐标/米/R-only/限制范围。
VCW_BakeNode 新增 selectedOnly:false 与 selectionSnapshot:undefined，旧调用仍默认整模型。
脚本局部调用先用 VCW_CaptureVertexSelection 在顶点模式捕获，再传 selectedOnly:true 和 selectionSnapshot；调用方负责释放快照。
核心回传数组保留前四项，追加第 5 项实际写入顶点数；面板捕获的快照在处理结束时释放，不创建选择辅助节点。
