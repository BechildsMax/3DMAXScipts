Mesh 动画检查与清理使用说明
===========================

# 项目概览

工具 v1.0.1，随 MaxZJTools v1.7.1 交付。扫描当前所选节点的 PRS（位置、旋转、缩放）关键帧；清理会修改动画，不自动保存场景。

# 功能说明与使用流程

## PRS 动画检查与清理

### 菜单/入口

MaxZJTools → Mesh动画检查；或运行 `tools/MeshChecker.ms`。

### 用途

定位选中对象的关键帧轨道，检查后删除对应 PRS 关键帧。检查和删除共用同一递归轨道清单。

### 流程图

    A[准备场景副本并选择节点] --> B[扫描位置 旋转 缩放子控制器]

### 参数说明

| 参数/操作 | 作用与输入范围/格式 | 默认行为及输出影响 | 约束与撤销 |
|---|---|---|---|
| 场景选择 | 当前选中节点集合 | 打开不扫描；点击检查/刷新才读取；空选择清空旧清单 | 扫描只读，不需要 Undo |
| 行复选框 | 布尔；选择扫描列表中的节点 | 有关键帧的行默认勾选；决定“清理选中对象”的范围 | 不是场景选择；列表禁止排序和编辑结果文本，避免行引用错位 |
| 清理选中对象 | 使用勾选行 | 删除这些节点扫描出的 PRS 关键帧 | 执行前复查扫描；共享控制器有范围外依赖时阻断；可通过 Max Undo 撤销 |
| 清理全部动画 | 使用当前扫描清单全部行 | 忽略行勾选状态 | “全部”仅指本次清单，不是全场景全部动画；可通过 Max Undo 撤销 |
| 刷新 | 无参数 | 按当前场景选择重建清单和关键帧时间 | 使旧清单失效；只读 |

无文件输入输出目录、筛选关键字、命名或覆盖操作。只删除实际列出的 PRS 关键帧，不保存、导出或复制资产。

### 输出结果

显示每个节点的位置、旋转、缩放关键帧时间和轨道键总数；同一时间在不同轴上有键会分别计数。执行后复查，显示删除数和失败轨道数；异常详情在 Listener。失败时已完成部分仍保留，可使用本批 Undo。

### 注意事项与已知限制

> 删除关键帧可能改变当前姿态。没有可清理关键帧不等于没有动画：约束、表达式、程序控制器、顶点动画、修改器和材质动画不属于本工具的完整清理范围。控制器子结构不支持时以错误为准，不承诺任意第三方控制器兼容。扫描后增加/删除关键帧、更换轨道、改变选择或删除对象须重新扫描。

# 安装与使用

按 [总说明](../Readme.txt) 安装；更新后重开窗口。依赖宿主 MAXScript 与 .NET WinForms，无需外部图片或导出依赖。源场景应先另存副本。

# 技术与兼容性

目标 Max 2022，本轮 Max 2024 尝试状态见 [验证记录](ArtTA-修复验证.md)。检查和写入均在宿主线程执行，使用节点依赖检查保护范围外共享控制器。撤销覆盖需真实宿主验收。

# 发布与更新规则

相关自动用例为 `tests/LegacyTools_Smoke.ms`：XYZ 子控制器、清理与回读、Undo、范围外共享轨道保护。另人工检查空选择后旧列表清空、勾选提交、扫描失效、删除后的姿态及保存重开。窗口重开即可加载更新，通常无需重启 Max；安装生命周期按总说明验收。
