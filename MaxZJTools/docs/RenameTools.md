重命名工具使用说明
==================

# 项目概览

工具 v1.2.1，随 MaxZJTools v1.7.1 交付。修改当前场景节点或材质名称，不改磁盘文件、不自动保存场景。

# 功能说明与使用流程

## 节点批量重命名

### 菜单/入口

MaxZJTools → 重命名工具；也可运行 `tools/RenameTools.ms`。

### 用途

给指定对象、材质或骨骼添加前后缀、替换文字或生成带编号的名称。对象和骨骼重叠时只处理一次。

### 参数说明

| 参数 | 作用与输入范围/格式 | 默认行为与输出影响 | 约束与撤销 |
|---|---|---|---|
| 模型对象 | 布尔；处理范围中的节点 | 开启；选中对象模式包括选择中的骨骼等节点 | 与骨骼类别去重；改名纳入本批 Undo |
| 材质 | 布尔 | 关闭；选中/按类型时处理范围内直接材质或 MultiMaterial 的第一层非空子材质；所有对象模式处理 sceneMaterials 顶层材质 | 实例共享材质的所有使用者看到同一名称；可 Undo |
| 骨骼节点 | 布尔 | 关闭；按旧识别规则选 BoneGeometry、Biped_Object 或名称含 Bone 的 helper | helper 名称匹配是启发式，须看预览；可 Undo |
| 对象选择范围 | 选中对象／所有对象／按类型 | 选中对象；空选择产生空清单，材质不会回退为全场景 | 所有对象显式扩大范围；可 Undo |
| 对象类型 | 几何体、灯光、相机、辅助对象、形状、所有骨骼 | 仅在按类型模式启用；材质从该类型对象收集 | 不能按未选类型隐式扩大范围；可 Undo |
| 重命名方法 | 前缀／后缀／替换／序列重命名 | 前缀；决定新名生成规则 | 参数改变后重做预览；可 Undo |
| 前缀、后缀 | 任意名称文本 | 均为空；分别加到名称开头或结尾，空文本保持原名 | 不自动避免重复添加；再次执行须重新预览；可 Undo |
| 查找、替换为 | 字面文本，区分大小写，不是正则表达式 | 均为空；查找为空不替换；替换为空可删除匹配文本 | 结果不能为空或全空格；可 Undo |
| 基础名称 | 文本 | Object；生成“基础名称_编号” | 结果重名时阻断；可 Undo |
| 起始数字 | 整数 0～9999 | 1；按清单顺序递增，对象→材质→未重复骨骼 | 不保证跨场景枚举顺序一致，以当前预览为准；可 Undo |
| 数字位数 | 整数 1～5 | 3；不足补零，超过位数不截断 | 不限制最终数字长度；可 Undo |

预览/刷新不写资产。新名称与清单内同类别或范围外同类别名称按不区分大小写检查；已有未改名的重复项保留。材质冲突检查含场景子材质。节点与材质属于不同命名类别。本工具没有输入/输出目录、文件匹配或文件覆盖操作。

### 输出结果

面板显示目标名称映射，执行后显示已修改、失败、未变化数量；失败详情输出到 Listener，带工具名和版本。部分失败不会报告整体成功；已完成部分保留在本批撤销组。

### 注意事项与已知限制

> 预览后选择、目标名称或参数变化会阻断执行；外部名称冲突也会重新检查。共享材质并非独立副本。没有大小写转换或专用删除数字功能。按钮“撤销 Max 上一步”调用宿主全局 Undo，期间做了其他操作时会先撤销其他操作；不是工具专属历史。

# 安装与使用

按 [总说明](../Readme.txt) 安装，更新后重载 Init 并重新打开窗口。保留完整工具包。该工具无额外资源、导出或第三方依赖。

# 技术与兼容性

目标宿主沿用 Max 2022；本轮另尝试 Max 2024 验证，实际状态见 [验证记录](ArtTA-修复验证.md)。使用 MAXScript、材质和节点 API。写入纳入 Max Undo，恢复仍需目标宿主验证；场景保存由用户负责。

# 发布与更新规则

运行 `tests/LegacyTools_Smoke.ms` 的重命名用例，并人工检查面板、共享材质与撤销。验收包括空选择零写入、同骨骼只改一次、过期预览拒绝、重名阻断、保存副本后重新打开。纯说明变化无需重启；源码更新重开窗口。
