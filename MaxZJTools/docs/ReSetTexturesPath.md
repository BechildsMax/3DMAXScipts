贴图路径重设使用说明
====================

# 项目概览

工具 v1.0.1，随 MaxZJTools v1.7.1 交付。修改场景 Bitmaptexture 的文件引用；不改名、移动、复制或覆盖磁盘图片，不自动保存场景。

# 功能说明与使用流程

## 丢失贴图引用修复

### 菜单/入口

MaxZJTools → 贴图路径重设；或运行 `tools/ReSetTexturesPath.ms`。

### 用途

显式扫描场景材质及其子材质/子贴图，按目录、文件名前缀或文件名文字修复丢失引用。共享贴图实例只出现一次。

### 流程图

### 参数说明

| 参数/操作 | 作用与输入范围/格式 | 默认行为与输出影响 | 约束与撤销 |
|---|---|---|---|
| 扫描全场景丢失贴图 | 无参数；显式读取全部 sceneMaterials 及其子树 | 打开窗口不自动扫描；仅列非空且文件不存在的 Bitmaptexture | 扫描只读；不覆盖环境贴图、所有渲染器专用贴图或外部引用系统 |
| 丢失文件选择 | 多选列表 | 扫描后默认全选；全选/取消选择控制当前清单 | 共享实例去重；引用仍被场景使用才允许写入 |
| 新路径 | 绝对目录或 UNC 目录 | 空；“应用新路径”保留文件名和扩展名 | 目录必须存在；目标文件不存在则跳过；改引用可 Undo |
| 旧前缀 | 文件名开头的字面文本，区分大小写 | 空；为空时仅添加新前缀 | 非空且不匹配则跳过，不强行加新前缀；改引用可 Undo |
| 新前缀 | 文件名前缀文本 | 空；可删除匹配的旧前缀 | 与旧前缀不能同时为空；结果必须是合法文件名；可 Undo |
| 查找 | 文件名主体中的字面文本，区分大小写，非正则 | 空；执行时不能为空 | 不替换目录和扩展名；不匹配则跳过；可 Undo |
| 替换为 | 文件名主体替换文本 | 空；可删除匹配内容 | 不允许通过分隔符变成目录路径；目标不存在则跳过；可 Undo |

没有输出目录：新路径是已有图片的查找位置。不同原路径映射到同一个目标文件时整次预览阻断，要求分别选择处理；相同原路径的不同贴图实例可共同指向同一图片。无文件覆盖策略，因为不写图片。前缀和替换操作保留原目录。

### 输出结果

面板及 Listener 列出旧/新路径和跳过原因，确认后写入，报告“引用已改、文件已找到、跳过、失败”四项。文件存在只证明可定位，不证明格式、内容或贴图效果正确。

### 注意事项与已知限制

> 修改共享贴图会影响所有引用该实例的材质和节点。仅扫描 Bitmaptexture，材质外的贴图或其他插件类型不承诺覆盖。没有递归搜索磁盘、同名图片内容比较、自动打包、UDIM 解析或图片复制功能。执行前引用或文件状态变化会拒绝继续；写入中断可能部分完成，结果与日志会说明。

# 安装与使用

按 [总说明](../Readme.txt) 安装并重开工具窗口。源图片需用户自行保留/复制到目标目录，本工具只修改引用。更新无需重启；实际安装验证见总说明。

# 技术与兼容性

目标 Max 2022；本轮 Max 2024 尝试状态见 [验证记录](ArtTA-修复验证.md)。使用内置 MAXScript 和 .NET 路径 API，无额外依赖。每批修改进入 Max Undo，不自动另存场景。

# 发布与更新规则

用 `tests/LegacyTools_Smoke.ms` 检查多维材质遍历、共享贴图去重、目标存在/缺失和撤销；人工检查同名冲突、UNC 路径、前缀不匹配、取消确认及真实渲染结果。性能范围按真实样例记录，不宣称任意大场景支持。
